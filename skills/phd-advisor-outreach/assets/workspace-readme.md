# 申博资料：这个文件夹怎么用

这是你申博全程的工作文件夹。你负责往里放材料，我负责整理档案、名单、邮件和各种表。所有内容都只存在你的电脑上。

## 整个过程分五步

| 步骤 | 做什么 | 你会得到 |
|---|---|---|
| 1 了解你 | 我看你的材料，再和你聊一聊 | 一份申请者档案 |
| 2 定位 | 判断你在什么层次有竞争力，一起定好往哪申 | 一页定位结论 |
| 3 导师名单 | 导师筛不全，我分轮找，每轮 30 位；怎么筛由你选（综合最优、按地区、按学校层级、按你喜欢的学校、按方向） | 一张导师名单表，含职称、头衔、方向、契合点 |
| 4 深查与写信 | 先做一份你的邮件母版；再从名单里一批批地选，每位导师我先深查，再单独写邮件 | 邮件母版；每位导师的核查记录和邮件草稿 |
| 5 发出与跟进 | 你发邮件；老师回信后贴给我，我帮你看是什么意思、把回复写好；没回的我提醒你跟进；有意向的老师记进意向导师表 | 一本联系账本，每封回信的回复，一张意向导师表 |

整个过程的目标只有一个：帮你争取到线上展示自己工作的机会，或者加上老师的微信。邮件只是敲门，坐下来谈才是关键。

不一定要按顺序。手头已经有想联系的老师，可以先写那一封。任何时候不知道该做什么，问我“现在到哪了、下一步是什么”就行。

## 文件夹是按申博的流程分的

```text
申博资料/
├── 01_我的材料/      你的原始材料
├── 02_档案/          我整理的关于你的信息
├── 03_申请材料/      对外用的定稿，每位导师通用
├── 04_导师联系/      导师名单表，和联系过的每位导师
├── 05_意向导师/      给了你正向回应的导师，单独放在这里
├── 06_院校报名/      每所学校的简章和报名材料
└── 07_临时文件/      我的中间产物，你不用管
```

| 文件夹 | 谁来放 | 放什么 |
|---|---|---|
| `01_我的材料/简历/` | 你 | 现有的简历，任何版本都可以 |
| `01_我的材料/论文与稿件/` | 你 | 已发表的论文、在投的稿件、补充材料、投稿状态的截图或邮件 |
| `01_我的材料/成绩与证书/` | 你 | 成绩单、英语成绩、获奖证书 |
| `01_我的材料/其他经历/` | 你 | 开题报告、组会汇报、项目材料、学位论文草稿 |
| `02_档案/` | 我 | 申请者档案、邮件母版、联系账本、访谈记录。你可以随时打开看和改 |
| `03_申请材料/简历/` | 你和我 | 准备发给导师的简历定稿 |
| `03_申请材料/工作介绍/` | 你和我 | 介绍你研究工作的文件定稿 |
| `03_申请材料/研究计划/` | 你和我 | 博士阶段研究计划的通用版 |
| `03_申请材料/汇报PPT/` | 你和我 | 工作汇报 PPT 的通用母本 |
| `04_导师联系/筛选表/` | 我和你 | 每轮 30 位的导师名单表。你已经有的名单也放这里 |
| `04_导师联系/某位导师/` | 我 | 我深查过、写过信的导师各一个文件夹：核查记录、邮件、回信 |
| `05_意向导师/意向导师表.xlsx` | 我 | 见下面的专门说明 |

| `06_院校报名/` | 你和我 | 每所要报名的学校一个文件夹：招生简章、报名要交的材料、时间节点 |
| `07_临时文件/` | 我 | 我生成的中间文件 |

## 意向导师这一块

联系过的导师会有几十位，真正往面试和报名推进的只有几位。这几位单独放在 `05_意向导师`，你打开它，看到的就是眼下最该管的事。

**意向导师表**：每位给了你正向回应的老师占一行，记着这些：

- 意向状态（欢迎报考、愿意进一步交流、已约面试、面试后待反馈、明确接收意向等）和你自己的倾向（首选、备选、保底）
- 名额情况，有没有加上微信
- 面试或交流的日期、形式和要求，你准备到哪一步了
- 学校的报名时间、报名方式和要交的材料
- 下一步要做什么、最晚哪天做

它的用处：

1. 一眼看到所有在谈的老师各到哪一步。
2. 面试和报名的日期都在上面。你每次回来我会先看这张表，快到期的提醒你。
3. 手里有几个意向需要取舍时，摆在一起比。
4. 到了报名阶段，照着它逐校准备。

这张表由我来填和更新，你也可以自己改。

**每位意向导师的文件夹**分成五类：

| 子文件夹 | 放什么 |
|---|---|
| `往来记录/` | 核查记录、邮件、回信，微信沟通的要点 |
| `文献/` | 这位老师的论文和精读笔记 |
| `PPT/` | 给这位老师的汇报 PPT |
| `面试/` | 面试准备、老师问过的问题、复盘 |
| `专属材料/` | 为这位老师改过的研究计划、简历等 |

一位老师回复有意向后，我会把他的文件夹从 `04_导师联系` 搬到这里并分好类，然后告诉你。

接着是**读懂这位老师**：我会给你挑五篇理解他核心方向的论文，每篇告诉你为什么选它、重点看哪里、和你有什么关系、面试时可以怎么提，放在他的 `文献` 文件夹里。读不懂的地方贴给我；读完我们一起整理一页“对课题组的理解”。老师约了交流时我会直接开始；你也可以随时说“帮我看看某老师该读哪些论文”。

同时我会去查这位老师所在学校的招生简章，把报名时间、要交的材料和英语等硬性要求记进意向导师表和 `06_院校报名`。报名系统需要你自己填。

两条约定：

- **通用的和专属的分开放。** 给所有老师都能用的放 `03_申请材料`；为某位老师改过的版本只放他自己的文件夹，这样发邮件时不容易附错。
- **导师的文件夹是慢慢长出来的。** 我对一位老师做深查时才建他的文件夹；他有了意向，才会搬进 `05_意向导师` 并分出五个子文件夹。

## 现在请你做的事

1. **把你手头已有的资料放进来。这一步最能加快进度**：你放得越全，我要问你的越少，了解得也越准。建议放这些，有什么放什么，没有的不用现做：

   | 资料 | 放哪 |
   |---|---|
   | 做好的简历（最重要） | `01_我的材料/简历/` |
   | 论文和稿件的全文，包括还在投的 | `01_我的材料/论文与稿件/` |
   | 已经做过的工作介绍、研究计划 | `03_申请材料/` |
   | 拿不准放哪的 | 直接放在 `01_我的材料/`，我来归类 |
   | 开题报告、组会或答辩的 PPT、学位论文草稿 | `01_我的材料/其他经历/` |
   | 成绩单、英语成绩、获奖证书 | `01_我的材料/成绩与证书/` |
   | 以前写过的套磁邮件、联系过的导师名单、导师的回信 | `04_导师联系/筛选表/`，或直接发给我 |
2. 已经联系过导师的，把名单或邮件放进 `04_导师联系/筛选表`，或者直接告诉我。
3. 放好后告诉我一声，我读完会先讲讲我读到的你，再问几个材料里看不出来的问题。

## 待办和提醒

我没法主动找你，所以每次对话结束时我会更新两个文件，都在这个文件夹的最外层：

- `待办与日程.md`：你接下来要做的事、要记住的日子、正在等的事。
- `申博提醒.ics`：面试时间、报名的开始和截止、该跟进的日子。导入手机日历后，到时候日历会提醒你。

怎么把 `申博提醒.ics` 导进手机：

| 设备 | 步骤 |
|---|---|
| 苹果手机 | 把文件发到手机（微信“文件传输助手”或发邮件给自己）。在微信里点开文件，点右上角的“…”，选“用其他应用打开”，选“日历”，再点“添加全部” |
| 安卓手机 | 把文件发到手机，点开后选“用其他应用打开”，选系统自带的“日历”，确认导入 |
| 电脑 | 双击文件，用 Outlook 或系统日历打开，点“保存”或“导入” |

导完打开手机日历，翻到最近的那个日期，能看到标题以“申博｜”开头的日程就成功了。记得把日历的通知打开。

日期有变化或有了新日期，我会重新生成这个文件并告诉你，你需要再导入一次；日历里出现重复的，把旧的那条删掉。导不进去也没关系，照着 `待办与日程.md` 里的日期在手机上手动设提醒就行。

## 下次怎么继续

我没有跨对话的记忆，进度全靠这个文件夹。下次开新的对话时，告诉我继续申博，并让我读这个文件夹，我会先看 `02_档案` 里的档案和账本，问你哪几位老师回了信，再接着做。

所以这个文件夹不要删，里面的文件也不要改名。

## 几点说明

- `02_档案/申请者档案.md` 是之后所有名单和邮件的依据。里面关于你的每一条，你觉得不准都可以改，或者告诉我改。
- 我不会移动或删除你放进来的任何文件。
- 邮件草稿写好后只是保存在这里。没有你的明确同意，我不会发出任何邮件。
- 这个文件夹里有你的个人信息和未发表的研究内容，不要随意分享给别人。
