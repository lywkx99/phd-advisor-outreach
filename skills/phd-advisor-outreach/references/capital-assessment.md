# 资本评估：写足、补上、不过线

这个文件回答三个问题：申请者的资本怎么记、怎么评、评完之后目标怎么定。指导思想是去保守化：技能、论文、能力都往足里写，同时不过分夸大。评估结果写入档案的“专家结论”部分，用户确认后生效。

## 一、为什么要去保守化

- **导师只看得到写出来的东西。** 邮件里没写的技能和能力，对导师来说就是没有。申请者自己觉得“只是用过，不算会”，于是不写，等于白白丢掉一项资本。
- **申请者普遍少写自己。** 背景普通的人尤其如此，习惯用“接触过”“略有了解”“参与了一些”。这类词在导师眼里等于不会。
- **邮件的任务是争取一次交流的机会。** 从发出邮件到面试之间有时间。现在讲不透的地方，可以在这段时间里补上，而你就是带他补的人。
- **谨慎过头会带偏整个策略。** 资本估低一档，名单就整体偏低，本来够得着的组连试都没试。

所以默认的方向是：有真实基础的，就写上、写足，然后补上。

## 二、三个区

去保守化不是什么都往大里说。先分清一条信息属于哪个区。

| 区 | 包括什么 | 做法 |
|---|---|---|
| 硬事实 | 论文状态、作者顺序和本人位置、期刊、DOI、数据和结果、学历、成绩、证书、奖项 | 照实写，不往上加一个字。这些都查得到，一处不实，其余内容全部失去可信度 |
| 弹性项 | 技能的熟练程度、能力的概括、本人在工作中的角色、工作的意义和亮点、学过用过的工具和方法 | 往上写足，然后补上 |
| 过线 | 没做过的实验、没得到的结果、完全没碰过的技术写成做过、没有核实的“首次”、在审写成已发表、别人的工作写成自己的 | 不写 |

一条弹性项能不能写上去，问两个问题：

1. **有没有真实的基础？** 用过、做过一部分、系统学过，都算。完全没碰过不算。
2. **到面试那天答得上吗？** 现在答得上最好；现在答不上，但从现在到面试之间补得上，也可以。

两个都是“是”，就写上。写上的同时做三件事：记入档案的补课清单；当面告诉用户你写了什么、后面怎么补；到了面试阶段兑现。

> “你的 caDNAno 我先写上了，按‘掌握 caDNAno 折纸结构设计’来写。后面如果进入面试，我再带你把折纸设计的基本原理过一遍，被追问时接得住。这样可以吗？”

两个问题里有一个是“否”，就不写成已有的能力，放进邮件的“希望学习”里。

## 三、怎么写足

| 常见的缩手缩脚 | 写足的做法 |
|---|---|
| “接触过”“略有了解”“参与了一些” | 用过并做出过东西的，写“掌握”“能够独立完成”；系统学过的，写“学习并使用过” |
| 只列做过的实验名称 | 把做过的事翻成能力：从“做过 RCA”到“能够独立设计并优化核酸扩增反应” |
| 主要由自己完成的工作写成“参与” | 直接写“主要由我完成”。导师给过指导、改过稿，不妨碍这样写 |
| 在审的稿件不敢提 | 状态照实写，但它是有效的资本：列进成果段，随信附上稿件，定位时计入 |
| 用过但讲不透的技能不写 | 写上，列入补课清单 |
| 工作的亮点埋在细节里 | 让用户说出这项工作最值得讲的一点，放在这一段的最前面 |
| 因为院校背景普通就自动降一档 | 院校背景如实写，不因此给成果和能力打折 |

记录和评估时的规则：

- 介于两档之间，取高的一档，并记下要撑住这一档还需要补什么。
- 能力和角色的概括，在真实范围内选最有分量的说法。
- 硬事实不在此列：状态、署名、数据，是什么就写什么。

## 四、追问阶梯：用来找缺口，不是用来降档

对每项工作和每项技能，问五层：

1. 这部分是谁动手做的？
2. 具体怎么做的，关键条件是什么？
3. 为什么选这个方案，没选别的？
4. 失败过吗，怎么解决的？
5. 支持这个结论的直接证据是哪一张图？

用法：

- 第一层的答案决定能不能写成本人做的。不是本人做的，不写成本人做的，这是红线。
- 第二到第五层答不上来的地方，不用来把技能降档，而是直接变成补课清单的条目。
- 问的时候告诉用户目的：“我问这些不是考你，是想知道面试前要帮你补哪里。”

## 五、补课清单

写进了档案或邮件、但用户现在还讲不透的内容，都记在档案的补课清单里。每项写：现在的程度、邮件里怎么写的、面试前要补什么。

- 清单上的每一项都是你对用户的承诺。用户收到面试或交流邀请时，先翻这张表，带他逐项过一遍：基本原理、关键参数、导师可能追问的两三个问题。
- 补课清单太长，说明写得过了头，或者离面试太近补不完。这时和用户商量，把补不上的几项收回来。
- 用户不愿意补、或者你判断短期补不上的，不写成已有能力。

**一项补课怎么做。** “带他过一遍”不是丢给他一篇教程，而是按面试会被怎么问来准备。每一项按这五步，通常二三十分钟：

1. **三句话讲原理。** 你先讲，再请他用自己的话复述一遍。
2. **关键参数和为什么。** 这项技术里最容易被问到的两三个条件，各自为什么这样设。
3. **回到他自己的数据。** 他当时是怎么做的、结果是哪张图。面试时讲自己的数据最稳。
4. **导师最可能追问的三个问题**，各给一个他答得出口的回答，不背稿。
5. **模拟追问一轮。** 你扮导师连问三层，答不上来的地方再补。

补完把要点存成 `面试/补课_项目名.md`，放在对应意向导师的文件夹里（通用的放 `03_申请材料`），并把补课清单里这一项的状态改成“已补”。时间紧时先补这位导师的方向最可能问到的几项。

## 六、各维度的档位

下面的档位是通行经验，用来形成判断，不是录取预测。不同学科的产出节奏差别很大，评估前先问用户：“你们领域里，硕士毕业时一般有什么成果？组里往年申博成功的师兄师姐是什么水平？”用这个答案校准。

**科研产出**

| 档 | 描述 |
|---|---|
| P0 | 没有成文的成果 |
| P1 | 有稿件在写或已投出，还没有审稿结果 |
| P2 | 有非一作的已发表论文；或一作稿件在同行评审、修回阶段 |
| P3 | 一篇一作或共同一作的原始研究已发表或已正式接收 |
| P4 | 两篇及以上一作已发表；或一篇发表在本领域公认的主流高水平期刊 |
| P5 | 多篇一作发表在本领域公认的高水平期刊 |

在途的稿件计入资本：已发表的定基础档位，在审或修回的一作稿件往上加半档，比如“P3，另有一篇一作在审，按 P3 偏上定位”。同时告诉用户，这篇如果被拒，定位要往回收多少。

导师第一、本人第二的论文单独说明，在很多单位它被视同学生一作，写的时候把署名情况讲清楚，不改写作者顺序。综述、专利、会议摘要、竞赛奖项都列出来。

**研究独立性**

| 档 | 描述 |
|---|---|
| I1 执行 | 按给定方案做实验，能讲清自己做的部分 |
| I2 半独立 | 参与方案设计，能独立排查问题、分析数据、写初稿 |
| I3 独立 | 想法、设计、实验、分析、写作主要由本人完成 |

很多硕士生实际在 I2 到 I3 之间，却把自己说成 I1。只要主要环节是他做的，就按高的一档记，面试前把“每个决定为什么这样做”补清楚。

**技能与方向的对口程度**

不单独评档，而是针对目标方向列三栏：扎实的、用过的、只了解的。前两栏都可以作为已有技能写，第二栏配补课。同一个人对不同导师，这一项的强弱不同，在契合度分析里逐个判断。

**院校与学位背景**

如实记录本科、硕士院校和学位类型，不评档。它主要影响邮件被打开后的第一印象，能被成果和方向对口程度部分抵消。怎么向用户讲这件事，见 [权衡与现实](tradeoffs.md)。

**硬门槛**

英语成绩、学位类型、应届或往届等报名资格。它不评档，而是逐校判断风险，单独写在下面的“硬门槛”一节。

**支持条件**

现导师是否知情并支持、推荐信能找谁写、有没有人能引荐。

**时间与确定性**

毕业时间是否确定、学位论文进度、最晚什么时候需要定下来。

## 七、硬门槛：筛选时判断英语卡不卡

英语成绩在了解阶段问一句、记下来就行。它的风险放到筛导师时逐校判断，不在访谈里展开。

**筛选时**：每所学校查一次当年简章对英语的要求（简章没出查上一年的并注明），和用户的成绩一比，填进名单表的“英语门槛”一列。一所学校查一次，同校的导师都能用。写法：

| 情况 | 这一列怎么写 |
|---|---|
| 学校不要求六级，或用户已满足 | 不卡（写明要求，如“四级即可”“要求六级 425，已过”） |
| 用户只有四级，学校要求六级 | 卡六级（写明要求的分数） |
| 用户过了六级，但分数低于学校要求 | 卡分数（如“要求六级 460，现 430”） |
| 刚好在线上，或只有上一年的要求 | 临界（写明哪一点没确认） |
| 找不到简章，或没有联网 | 未查到 |

不凭印象报分数线，每一条都要有来源链接。

**交付名单和之后给建议时**：对卡住的那几位，给两样东西，不必长篇展开。

- **替代方案**。看这所学校的简章有没有写：其他英语考试成绩、英文一作论文、英语国家的学习经历、学校自己组织的英语水平测试、先录取后限期达标。有哪条算哪条，以简章原文为准；简章没写的，可以在邮件或交流时问导师。还有一条是重考：把下一次考试、出成绩的时间和这所学校的报名截止时间放在一起看来不来得及。
- **可冲性**。给一个判断，一句理由：

| 可冲性 | 什么情况 |
|---|---|
| 可冲 | 简章明文有替代条件而用户满足；或者重考来得及 |
| 有条件可冲 | 要求写得有弹性，或需要导师、学院出说明；值得发邮件时顺带问清 |
| 不建议冲 | 明文硬卡，没有替代条件，重考也来不及 |

> “这 30 位里有 4 位所在的学校卡六级，你目前只有四级。其中甲校的简章写了‘有英文一作论文可视为达标’，你那篇已发表的符合，可冲。乙校十二月考、二月出分，它的报名三月才截止，重考来得及，也可冲。丙校和丁校是明文硬卡，一月就截止，不建议冲，我把它们排到了表的最后。”

选联系批时，“不建议冲”的先不选。

**用户没过六级时。** 这是很常见的情况，也是很多人最焦虑的一点。不必在访谈里展开，但筛选时要让他感到这件事被认真对待了：

- 先说一句实话：各校各学院对英语的要求不一样，有的卡六级，有的不卡，有的有替代条件，要逐校查才知道，不是“没过六级就不能申”。
- 提出筛选口径时，把“不卡六级优先”作为一个选项给他。
- 名单表里每所学校都标清楚，让他一眼看到哪些能报。
- 还打算再考的，把下一次考试和出成绩的日期写进待办和日历，并对照各校的报名截止时间。
- 邮件里不必主动写没过六级；简历上照实写已有的成绩。导师问到英语时照实回答，同时说明替代条件或重考的安排。

学位类型、应届或往届这类其他硬条件，遇到有明文限制的学校，记在名单表的“待深查的问题”里，深查时核对。

## 八、从资本到定位

**不要按头衔猜门槛，去看这个组实际收了谁。** 对每位候选导师，尽量查课题组近年博士生的来源：本科和硕士院校、入学前有没有论文。课题组主页的成员页、学生的学位论文、学院的拟录取公示都是来源。查得到就用它，查不到就标“未知”，退回下面的经验判断。

| 档位 | 含义 |
|---|---|
| 冲 | 该组近年学生的背景或入学前成果明显高于申请者；或者是资深大组，申请者多、名额少 |
| 稳 | 方向对口，申请者的资本和该组近年学生相当 |
| 保 | 申请者的资本明显高于该组近年学生；或者导师已明确表示有名额并欢迎 |

定位时同样不要保守：

- 拿不准一位导师算冲还是稳时，按稳来联系，不要自己先把他划出去。
- 方向高度对口是最有效的杠杆。导师正缺会这门技术的人时，背景的权重会下降，这种组值得往上够。
- 刚建组的青年导师往往更看重能不能马上干活，对院校背景相对宽容，但名额和培养条件要核实。
- 资深大组的邮件量大，没有引荐又没有突出成果时，回复的可能性低。可以试，数量要控制。
- “保”不是随便找一个。保底的组也要方向能接受、导师有名额、能正常毕业。

**配比。** 由用户的风险偏好和时间决定，你给建议和理由。时间紧、不能接受空档的，多放保；能接受再等一年的，可以多放冲。

**随反馈调整。** 第一批邮件发出后，回复情况是最好的校准信息。稳档普遍没有回复，先查邮件写得够不够足，再考虑调整定位；冲档有回复，可以再往上够。

## 九、评估结论怎么写

资本评估和定位的结论是“一页定位结论”的主体。访谈第 8 轮把它和方向、筛选范围、邮件主线合在一起讲给用户，确认后写入档案。其中资本和定位部分包含：

1. 各维度的档位，每个附一句依据。
2. 优势，写成具体事实，写足。
3. 一到两条短板，以及怎么补、你能帮什么。
4. 在途的事项及其影响，比如“在审的那篇如果接收，产出到 P4”。
5. 冲、稳、保三档各自的目标画像，各一句话。
6. 补课清单里目前有哪几项。

不给录取概率，不说“一定能”“肯定不行”。讲给用户时先讲优势，短板直接讲，并且每条短板后面跟着补的办法。
