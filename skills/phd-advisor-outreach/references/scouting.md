# 找导师与核实名单（初筛）

开始前确认档案过了闸门 A。筛选用到的范围和权重都从档案的“筛选参数”里读，不用你自己的默认偏好。参数是 `[假设]` 的，交付时要说明。

**这一步是初筛，不是深查。** 对每位导师只查到能排序的程度，结果全部写进名单表。细看论文、核实当年名额、一作观察、学生背景，这些留到用户选定联系批次之后的单个导师深查再做，见 [流程地图](workflow.md) 第 4 步。

两个容易混的词：

- **筛选轮**：一次初筛，产出 30 位导师的表。
- **联系批**：从表里选出来、准备深查和写信的五到八位。

## 一、分轮筛选：每轮 30 位，先让用户选口径

符合条件的导师不可能一次筛全，也没有必要。做法是分轮：每轮按一个筛选口径找 30 位，按优先级排好，交付后再决定下一轮怎么筛。

### 开始前先问用户这一轮怎么筛

不要自己默默定一个范围就开始。根据档案里的信息，拟出四到六个口径，推荐的放第一个并说理由，请用户选。

| 口径 | 什么时候提出 | 这一轮怎么找 |
|---|---|---|
| 综合最优 | 总是提出，通常作为推荐 | 不限地域和学校，按档案的全部权重综合判断最适合的 30 位 |
| 按地区 | 档案里有地域偏好或硬约束 | 只在指定的城市或省份里找，如“江浙沪” |
| 按院校层级 | 用户看重学校牌子，或有层级底线 | 只在指定层级里找，如“985 和中科院” |
| 按心仪院校 | 用户提到过想去的学校 | 在这几所学校里把相关院系和平台查全 |
| 按特定方向 | 方向总结里有一个他特别想做的子方向 | 只盯这一个子方向，全国范围找做得最好的 |
| 放宽到大方向 | 最贴合方向下对口的组已经筛得差不多 | 在方向总结的大方向范围里往外找 |
| 不卡六级优先 | 用户没过六级，或六级分数偏低 | 先查各校对英语的要求，优先找不卡的、或有替代条件的学校 |
| 按导师类型 | 用户明确偏好青年导师，或看重人才称号 | 如“近五年独立的青年导师”“有国家级人才称号的课题组” |
| 用户自己的优先级 | 总是留这个口子 | 按他说的来 |

口径可以叠加，比如“江浙沪的 985”。叠加后范围太窄、凑不够 30 位时，事先告诉用户。

问的时候要具体到他的情况，不要念菜单：

> “导师不可能一次筛全，我按轮来，每轮 30 位，按优先级排好给你。第一轮怎么筛，根据你的情况我想到这几种：
> 一、我综合判断最适合你的 30 位，不限地区和学校。我推荐先做这个，因为你的方向比较窄，先看全国范围内谁和你最对口，心里有个底。
> 二、只看江浙沪，你说过最想去那边。
> 三、只看 985 和中科院的研究所。
> 四、你提过想去的那三所学校，我把里面相关的课题组查全。
> 五、只盯 DNA 纳米技术这一个方向，全国找。
> 你想先做哪一种？有别的优先级也可以直接告诉我。”

用户说“你定”时，按综合最优做，并告诉他你是按这个口径做的。

### 做的过程中：先出十位，校准了再补齐

30 位是不小的工作量。方向理解偏了，整轮都白做。所以先把最靠前的十位做出来给用户看。不问一串问题，只请他说不对的地方；他没意见就按这个方向补齐剩下的二十位。

> “先出了十位，在下面。方向偏了，或者有哪位一看就不想去，告诉我；没问题我就按这个方向把剩下二十位补齐。”

用户说“不用看，直接做完”时，就直接做完。

### 交付前自查

这张表是用户之后做决定的依据，交出去之前逐项过一遍：

- 每位导师都有官方主页的链接，邮箱来自官方页面。
- 职称、人才称号都有来源；查不到的写的是“未查到”，没有凭印象填。
- 没有重复的人；同名的已经区分；同一课题组的在“课题组与团队关系”里互相标了。
- 联系账本里已经联系过的，“已联系状态”如实填了，没有当成新人。
- 冲、稳、保都有，和用户定的配比大致相符。
- “英语门槛”一列每位都填了，写明了学校的要求。
- 每位的“推荐理由”和“契合点”是针对这位导师写的，不是同一句话换个名字。
- 排在前五位的，你能当面说清为什么排在这里。

### 对话里怎么展示

完整的表有三十多列，在对话里贴不下，贴了也没法看。完整的存成文件，对话里只贴一张精简表，让用户不打开文件也能做判断：

| 序号 | 姓名 | 单位 | 职称与头衔 | 现在在做什么 | 你能接在哪 | 档位 | 英语门槛 |
|---|---|---|---|---|---|---|---|

- 先出十位校准时贴这十位；整轮交付时贴前十位，其余二十位说一句“在文件里，同样的格式”。用户想在对话里看全，再贴。
- 表下面说明完整的表存在哪、还有哪些列（邮箱、主页、招生线索、团队关系、来源链接等）。
- 列名用用户听得懂的说法，“契合点”说成“你能接在哪”，档位直接写冲、稳、保。

### 一轮做完之后

- 交付时说明这一轮的口径、覆盖了哪些单位和入口、哪些还没查。
- 不够 30 位时，报实际数量和原因，不凑数。建议放宽哪个条件。
- 问下一轮：换一个口径再筛 30 位，还是先从这一轮里选联系批开始深查。两件事可以交替做，不必等所有轮次筛完才开始联系。
- 各轮之间去重。同一位导师只出现一次，在“筛选轮次与口径”一列里记下他是哪一轮进来的。
- 所有轮次合并在同一个文件里，每轮一个工作表，或者用“筛选轮次”一列区分。

## 二、每一轮内怎么排优先级

先按 [契合度分析](fit-analysis.md) 判断交集的级别，再按 [资本评估](capital-assessment.md) 的“从资本到定位”判断每位导师属于冲、稳、保哪一档。初筛阶段这两项都是初判，依据是论文题目、主页和招生页面；深查后可能调整。

排序依次看：

1. 和导师当前核心问题的交集，以及迁移路径是否合理。
2. 博士培养是否可达：资格、招生线索、是否活跃。
3. 档案里用户最看重的三项（比如导师亲自指导、平台、一作机会）。
4. 这一轮口径本身的偏好（比如按地区筛时，用户最想去的城市靠前）。
5. 联系的价值和时机。
6. 英语门槛：同等条件下不卡的排前面；判断为“不建议冲”的排到表的最后，不占前面的位置。

30 位里冲、稳、保都要有，大致按用户定的配比。排第一的不一定是头衔最高的，而是综合起来最值得先联系的。

期刊水平和人才称号都是信号，不是排序的唯一依据。要看近期代表作的内容、连续性和导师在其中的角色。不编造影响因子。竞争有多激烈，没有数据就写未知。

## 三、表头：事先定好，每轮一致

表头固定为下面这些列，顺序不变。空白表见 [advisor-table-template.csv](../assets/advisor-table-template.csv)。用户已有自己的表格时，沿用他的列，把缺的列补在后面。

**排序与判断**

| 列 | 填什么 |
|---|---|
| 优先级 | 这一轮内的序号，1 最优先 |
| 档位（初判） | 冲、稳、保 |
| 推荐理由 | 一句话：为什么排在这里 |

**这个人是谁**

| 列 | 填什么 |
|---|---|
| 姓名 | 中文名；有英文名或别名的一并写 |
| 单位 | 学校或研究所 |
| 院系或实验室 | 所在学院、研究中心、重点实验室 |
| 城市 | |
| 院校层级 | 985、211、双一流学科、中科院、新型研究型大学、其他 |
| 职称 | 教授、研究员、副教授、副研究员、特聘或准聘研究员、助理教授等，按官方页面原文 |
| 博导资格 | 是、有线索、未知；写来源 |
| 人才称号与头衔 | 院士、国家杰青、长江学者、国家优青、海外优青或原青年千人、青年拔尖、青年长江，以及省部级人才计划等；写入选年份。查不到写“未查到” |
| 学术与行政职务 | 院长、所长、重点实验室主任、期刊主编或编委等 |
| 导师阶段 | 资深大组、成熟期、青年导师、新建组；写独立建组或入职的年份 |
| 课题组与团队关系 | 是否独立课题组；属于谁的大团队；和表内、账本内的谁同组 |

**他在做什么，和申请者的关系**

| 列 | 填什么 |
|---|---|
| 当前核心方向 | 一句话，依据近两三年的论文或主页 |
| 近年代表作 | 一两篇：题目、期刊、年份 |
| 契合级别（初判） | 强、中、弱 |
| 契合点 | 一句话：申请者能接在哪里 |

**能不能联系上**

| 列 | 填什么 |
|---|---|
| 招生线索 | 是否在招生目录里、主页有没有招生说明、申请方式 |
| 英语门槛 | 这所学校卡不卡用户的英语：不卡、卡六级、卡分数、临界、未查到，并写明学校的要求。一所学校查一次，同校导师通用。写法见 [资本评估](capital-assessment.md) 的“硬门槛” |
| 邮箱 | 官方页面上的邮箱；有备用的一并写 |
| 主页 | 官方个人页或课题组主页 |
| 已联系状态 | 照抄联系账本里的状态；账本里没有这位导师就填“未联系” |

**流程管理**

| 列 | 填什么 |
|---|---|
| 深查状态 | 未深查、已深查（日期） |
| 待深查的问题 | 初筛时没查清、深查要重点看的 |
| 筛选轮次与口径 | 第几轮、什么口径 |
| 核查日期 | |
| 来源链接 | 支撑以上信息的页面 |

深查完成后追加或回填的列：建议的切入点、目标年名额状态、近年学生背景、一作信号与样本数、深查后的契合级别和档位。

**关于职称、头衔和人才称号**

这几列用户很看重，也最容易出错。

- 只从官方来源填：单位官网的个人页、学院的师资介绍、基金委和主管部门的公示、学校的新闻报道。来源链接要能支撑。
- 按原文写，不升级也不合并。“青年研究员”不写成“研究员”，“校聘教授”不写成“教授”，省级人才计划不写成国家级。
- 同名的人很多。称号要和单位、研究方向对得上才能填。
- 查不到就写“未查到”，不写“无”。没查到不代表没有。
- 不凭印象或常识补。记忆里“好像是杰青”的，查不到来源就不填。
- 称号的名称历年有变化，按来源页面上的叫法写，并写上年份。

文件保存在 `04_导师联系/筛选表/`。能生成 xlsx 就用 xlsx，否则用 CSV 或 Markdown 表格，用户用表格软件都能打开。

查不到的格子写“未知”或“未查到”，不用好看的推测填满。

## 四、从多个入口找，避免漏掉青年导师

每一轮建一张“单位 × 入口”的覆盖表，每格标已查、无命中、待查。不声称穷尽。

入口：

1. 博士招生专业目录、报考导师名单、近年的导师资格名单。
2. 全体师资页，特别是青年研究员、特聘和准聘、近期入职、独立课题组名单。
3. 大课题组里的独立子课题组负责人、共同指导教师。
4. 在研基金、项目题目、课题组的研究报道。
5. 中英文主题检索，再由论文的通讯作者回查到人。

注意：

- 高校除了院系，还要查交叉平台、附属研究院和有明确博士培养路径的附属单位。科研院所查各研究所、中心的招生目录和独立课题组。
- 用论文反查只是入口之一。刚独立的导师可能还没有以通讯作者发表的高水平论文，不能因此漏掉。
- 资深导师不再亲自指导时，追踪组内的青年导师。要核实对方现在的身份和招生路径，博士后不能独立招生。
- 已有的导师表和联系账本先读，跨表去重。名单里的候选不等于已经联系。同名的人要区分，同一个人的备用邮箱要合并。

## 五、关键词矩阵

根据档案里的方向总结生成，分组检索，不要求各组的词同时出现：

- 最贴合方向和各个子方向的词：申请者最想做的问题和对象。
- 大方向和相邻方向的词：放宽范围时用的上位词，以及可以接受的相邻问题和平台。
- 方法和技术的词：申请者已有的、可以作为卖点的技术。
- 平台和应用的词：导师可能用来描述同一件事的另一套说法。

每组都准备中文和英文。同一个方向，不同领域的人叫法不同，把同义的说法列全。检索时站点限定搜索、姓名先搜、主题先搜都用。

## 六、准入判断

初筛阶段查到有线索即可，查不到的写“未知”，并在“待深查的问题”里记一笔。目标年份的名额、日常指导人这类细节通常要到深查时才查得清。

- 有资格、近期活跃、名额尚未公布：可以联系询问，名额写未知。
- 指导资格或培养路径缺少可靠证据：单独标为“待核实”，排在表的后部。
- 主页旧但有新论文或新项目：不能标为不活跃。
- 新导师的独立成果还少：把独立前的能力和建组后的证据分开写，标“独立成果尚早”。不包装成成熟课题组，也不直接排除。

## 七、交付名单时怎么交接

名单交付是流程里最容易断的地方：用户拿到一张表，不知道接下来该干什么。交付时讲清这几件事，话术见 [流程地图](workflow.md) 第 3 步：

1. 这一轮的口径是什么，覆盖了哪些单位，够不够 30 位。
2. 这张表是初筛的结果，契合级别和档位都是初判。
3. 下一步有两个方向：从这一轮里选第一个联系批，逐个深查、逐个写信；或者换一个口径再筛一轮。说你的推荐。
4. 你建议联系批选哪几位、为什么，请他确认或调整。
5. 英语门槛：这一轮里卡住的有几位，各自的替代方案和可冲性，一两句话说完。

选联系批时注意：每批五到八位；冲稳保搭配；同一课题组的不放在同一批；英语上“不建议冲”的先不选。

另外，有下面的情况要顺带说出来：

- 这一轮整体偏冲或偏保，和用户定的配比不一致。
- 限定范围内对口的组太少，建议讨论要不要放宽。
- 用户的档案还没过闸门 B，或者还没有邮件母版，写信前要先补。
