# 邮件模型：通用骨架、个人母版、导师定制

一封申博邮件由三层叠成。分清这三层，才知道换一位用户要重新设计什么、换一位导师只需要改什么。

| 层 | 是什么 | 对谁不变 | 什么时候做 | 放在哪 |
|---|---|---|---|---|
| 通用骨架 | 七个区块及各自的作用 | 所有用户 | 已经定好，见下文 | 本 skill 的 [email-skeleton.md](../assets/email-skeleton.md) |
| 个人母版 | 按这位用户的资本重新设计的底稿：区块取舍和顺序、固定段落、素材库 | 这位用户的所有邮件 | 写第一封邮件之前，和用户一起定 | 用户的 `02_档案/邮件母版.md` |
| 导师定制 | 针对一位导师改动的五处 | 只对这一封 | 每封邮件，深查之后 | `04_导师联系/姓名_单位/` |

**有了母版，每一封都从母版出发，不从零起草。** 从零写会让每封的身份、论文列表、格式和措辞各不相同，用户要逐字重审，也容易在某一封里把事实写错。母版把不变的部分定死，用户只需要看五处定制。

写具体词句时的规则（怎么写足、哪些是硬事实）见 [邮件写法](email-writing.md)。

## 一、通用骨架：七个区块

每个区块对应导师读到这里时想知道的一件事。

| 区块 | 导师想知道什么 | 母版里固定的 | 每位导师要改的 |
|---|---|---|---|
| 1 主题 | 谁、哪一级、什么方向 | 格式、姓名、院校 | 方向短语 |
| 2 首段 | 你是谁、什么时候毕业、想做什么、想要什么 | 身份、时间、询问招生的句式 | 方向短语 |
| 3 经历段 | 这个人做过什么、会什么，和我有什么关系 | 素材库里的备选句 | 选哪两三项、从哪个角度讲 |
| 4 核心工作段 | 他最拿得出手的一项工作是什么 | 这项工作的事实底稿 | 侧重点，以及接到导师方向的那一句 |
| 5 亮点区 | 有什么硬货。有论文的是成果段，没有论文的是亮点清单 | 全部 | 不改 |
| 6 导师段 | 为什么找我，来了能接在哪 | 无 | 全部重写，两三句 |
| 7 结尾 | 附了什么、还想要什么、怎么联系 | 附件句、请求线上汇报或加微信的句子、院校背景句（可选）、致谢、落款 | 一般不改；研究计划是为某位导师定制的时要核对 |

## 二、个人母版：为这位用户重新设计

母版不是把骨架的空填上。不同用户的资本不同，区块的取舍、顺序和分量都要重新定。每个设计决定都说给用户听并征求意见，定稿后请他通读确认。

### 1. 先判断卖点类型

| 用户的情况 | 母版怎么设计 |
|---|---|
| 有一作论文已发表 | 成果段完整列出并放在显眼位置；核心工作段写最强或最相关的那一项 |
| 工作扎实，但论文在审或在写 | 核心工作段加重，写出亮点和完成度；成果段照实写状态；附上稿件或工作介绍 |
| 没有论文 | 成果段换成亮点清单：由你从档案里挑三到五项最拿得出手的内容（项目、学位论文课题、核心技术、在写的稿件、专利、奖项、排名、英语），排成编号清单并用加粗突出；经历段写“能独立做什么”；附工作介绍 |
| 有一两篇论文，但项目或技能更有分量 | 论文和亮点合在一个清单里，论文排前 |
| 要换方向 | 首段后加一句转向的理由；经历段只讲能迁移的能力；导师段写清愿意从头学什么 |
| 院校、成绩、排名突出 | 这些信息提到首段 |
| 院校背景普通 | 首段只报事实，不解释；是否在结尾加一句院校背景句由用户定 |
| 有多项互不相关的工作 | 定一项作核心，其余进素材库；不把所有工作平铺 |

一位用户可能同时属于几类，取其中最强的卖点作为母版的重心。

### 2. 定主线

一句话说清他是谁、做过什么、想做什么。它会出现在主题和首段，其余部分都围绕它。主线取自档案的“邮件参数”，在这里定稿。

### 3. 选核心工作，写事实底稿和侧重点清单

- 核心工作选一项：本人最主导、最完整、和目标方向最相关的。
- **事实底稿**：三四句，写这项工作解决什么问题、怎么做的、得到什么。这部分对所有导师都不变。
- **侧重点清单**：同一项工作可以从哪几个角度讲，各对应哪类导师。写邮件时从中选一个角度，并写一句接到导师方向的话。

侧重点清单是母版里最值钱的部分。它决定了同一份经历能对多少类导师说上话。

### 4. 建经历素材库

把其余工作和技能各写成一两句备选句，每句注明适合哪类导师。写邮件时从中选两三项拼成经历段。素材来自档案的取材卡和技能三档，按“可以写到什么程度”一栏写足。

再定一句讲独立性的固定句（比如“这些课题从选题、实验到论文撰写基本由我独立完成”），前提是和取材卡一致。

### 5. 定固定句

首段、成果段的确认文本、附件句、再次询问招生的句子、请求交流的句子、院校背景句、致谢、落款。

- **请求交流的句子必带。** 每封邮件的目的都是争取一次线上展示的机会或加上导师的微信，这句话就是把目的说出口。提线上汇报、提加微信、还是两个都提，以及具体措辞，由用户定。用户想去掉时，讲清这句话的作用，仍然坚持不要的按他的意思办。
- 院校背景句是可选的，用不用、怎么措辞由用户定。
- 落款里留下电话或微信号，导师想加的时候不用再问。

### 6. 定亮点区

亮点区是导师扫读时最先停下来的地方，必须有，而且要排得醒目。

- **有论文**：用成果段。编号清单，每条两行：第一行是作者、题目、期刊、DOI，第二行是作者位置、状态、期刊信息。
- **没有论文**：用亮点清单。不能留空，也不能删掉让邮件没有硬货。你来挑内容，标准是有真实依据、和目标方向相关、导师一眼能看懂分量。最强的一项排第一。
- 挑了哪几项、为什么这样排，告诉用户并征求意见。他可能有你不知道的更好的素材。

两种清单的具体格式见 [email-skeleton.md](../assets/email-skeleton.md) 的“亮点区的两种格式”。

### 7. 定格式和长度

**加粗是给扫读的人看的。** 导师花几十秒扫一封陌生邮件，目光会落在加粗的地方。所以加粗要少而准：把全文加粗的地方连起来读，应该正好是“他是谁、做什么方向、有什么硬货、附了什么”。

默认采用这套格式，它来自一份实际使用过、效果得到验证的模板：

| 位置 | 格式 |
|---|---|
| 首段 | 只加粗两处：研究方向、目标年份的博士招生计划 |
| 经历段 | 整段不加粗 |
| 核心工作段 | 只加粗核心工作的名称 |
| 成果段 | 期刊名加粗斜体；作者位置（如“第一作者”）加粗；最有利的一项期刊信息加粗 |
| 亮点清单 | 每条的名称加粗；本人的角色加粗 |
| 导师段 | 不加粗；不放导师论文的期刊名和年份 |
| 结尾 | 只加粗附件名称 |
| 落款 | 姓名和电话或微信，各占一行 |

- 不整段加粗，不用下划线、颜色、多种字号。
- 称呼、问候、每个正文段、祝颂语、落款之间各空一行。
- 用户想改格式可以改，改了之后每封保持一致。
- 全文长度以导师一屏半内读完为准。

交付时提醒用户：把正文贴进邮箱后，要在邮箱里把这些地方设成真正的加粗和斜体，星号不能原样发出去。邮箱不支持格式时，去掉所有星号，靠分段和编号保持清晰。

### 8. 定披露边界

哪些未发表的内容只写方向、不写实现细节。

### 产出

把 [email-skeleton.md](../assets/email-skeleton.md) 复制到 `02_档案/邮件母版.md`，把固定槽填实，定制槽保留，后面附上侧重点清单和素材库。档案里的“邮件母版”一项填上路径和确认日期。

一份做好的母版是什么样、同一份母版怎样改给两位不同的导师，见 [示例](../assets/examples/email-master-example.md)。

用户急着要一封邮件、来不及先做母版时：直接写这一封，写完后告诉他哪些部分以后每封都不变、哪些是为这位导师写的，并把它整理成母版的初稿。

## 三、导师定制：改五处，不动四处

**改的五处**

| 槽位 | 改什么 | 依据（核查记录的哪一栏） | 常见错误 |
|---|---|---|---|
| 主题里的方向短语 | 落到和这位导师相关的具体方向：用最贴合的方向，加上方向总结里离他最近的那个子方向 | 现在在做什么 | 所有邮件用同一个宽泛的方向 |
| 首段的方向短语 | 和主题一致 | 同上 | 主题和首段不一致 |
| 经历段 | 从素材库选两三项，换成对这位导师有意义的角度 | 契合接口 | 复制整张技能清单；每封都选同样的几项 |
| 核心工作段的侧重点 | 从侧重点清单选一个角度，加一句接到导师方向的话 | 选定的接口 | 为了迎合导师改动工作的事实 |
| 导师段 | 两三句全部重写：他当前的具体工作，我已有的哪项经验，我想在他指导下学习或探索哪一环 | 现在在做什么、选定的接口 | 堆关键词；夸导师；只写“深受启发” |

**不动的四处**：身份信息、亮点区（成果段或亮点清单）、核心工作的事实底稿、结尾的固定句和落款。格式也不动，每封的加粗位置和排列都和母版一致。

**可能要动的**：附件。研究计划如果是为某位导师写的，发给别人前要换掉或改成通用版。

**定制的深度随契合级别变**

| 契合级别 | 怎么定制 |
|---|---|
| 强 | 五处都针对这位导师写；导师段写到具体的方法或体系 |
| 中 | 五处都改；导师段如实区分已有的经验和要学的部分 |
| 弱 | 先告诉用户交集弱。仍要写时，经历段讲能迁移的能力，导师段只写方向上的兴趣，不编造交集 |

**两个检查**

- 遮住导师的姓名，能不能从经历段、核心工作段的侧重句和导师段看出是写给谁的。
- 把这封和同一批的另一封并排看，五处定制里至少三处有实质的不同。只换了姓名和最后一段，说明没有定制。

## 四、母版什么时候要改

- 论文状态变了：改成果段的确认文本。
- 一批邮件的回复明显不好：和用户一起复盘母版，先看主线和核心工作段。
- 用户调整了方向或定位：重定主线和侧重点清单。
- 联系的导师类型多了：往侧重点清单和素材库里补新的角度，同时更新档案的方向桥接表。

改母版属于影响“怎么描述他”的决定，改之前说出来并征求意见。
