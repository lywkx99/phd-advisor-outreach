# 联系账本

申请者：【姓名】　目标入学年：【年份】　最近更新：【日期】

使用说明：

- 一位导师一行，深查时建行。状态用这几个词：`已深查`、`已发送`、`已跟进`、`已回复`、`转入意向`、`已关闭`。邮件写好交付后默认记 `已发送`，证据写“默认”；用户说没发时才用 `已起草（未发送）`。用户说以前联系过、但没有其他记录的，用 `用户确认已申请`。
- `已关闭` 要在“最新事件”里写原因：婉拒、跟进后无回复、决定不推进。
- 转入意向之后，“状态”一列停在 `转入意向`，这位导师现在什么情况看意向导师表。每一次往来的原话（邮件、微信、电话）仍然追加到下面的事件流水里。他落空了或决定不再推进时，改成 `已关闭` 并写原因。
- “证据”写这个状态是怎么知道的：默认、用户口述、回信、聊天记录、截图。
- 同一位导师的备用邮箱写在同一格里。同团队的导师在“团队交叉”里互相注明。
- 回信的原话摘要记在“最新事件”，不替导师升级措辞。
