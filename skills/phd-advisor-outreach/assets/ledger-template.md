# 联系账本

申请者：【姓名】　目标入学年：【年份】　最近更新：【日期】

使用说明：

- 一位导师一行，深查时建行。状态只往前追加，用这几个词：`已深查`、`已起草（未发送）`、`已发送`、`已跟进`、`已回复`、`转入意向`、`已关闭`。用户说以前联系过、但没有其他记录的，用 `用户确认已申请`。
- `已关闭` 要在“最新事件”里写原因：婉拒、跟进后无回复、决定不推进。转入意向之后的进展记在意向导师表里，这里不再更新。
- “证据”写这个状态是怎么知道的：用户口述、已发送邮件、回信、截图。
- 同一位导师的备用邮箱写在同一格里。同团队的导师在“团队交叉”里互相注明。
- 回信的原话摘要记在“最新事件”，不替导师升级措辞。
