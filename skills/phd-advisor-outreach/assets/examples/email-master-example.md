# 示例：一份母版，和它改给两位导师的样子

这个示例由一份真实使用过的申博邮件模板整理而来。姓名、院校、导师、电话、论文题目和 DOI 都已去掉，研究内容只保留到方向一级的描述。它用来展示母版的结构和定制的做法，不是可以照抄的文本。换一位用户，母版要按 [邮件模型](../../references/email-model.md) 重新设计。

## 一、这位申请者的情况

- 普通院校的硕士，分析化学方向，做功能核酸传感。
- 两篇一作已发表，一篇一作在审，一篇一作在编辑处理中。
- 卖点类型：有一作论文；院校背景普通。
- 博士想做的方向和硕士后期的工作一脉相承。

## 二、母版的设计决定

| 决定 | 内容 | 理由 |
|---|---|---|
| 重心 | 成果段完整列出；核心工作段写在审的那项 | 在审的工作最能代表他现在的水平，也最接近博士想做的方向 |
| 主线 | “做功能核酸传感出身，后期转向 DNA 分子机器的平台构建与动力学调控，博士想继续做 DNA 分子机器” | 把四篇工作串成一条线，而不是四个不相干的课题 |
| 独立性句 | “这些课题从选题、实验到数据分析和论文撰写，基本由我独立完成。” | 这是他相对于同档申请者最突出的地方，每封都保留 |
| 院校背景句 | 用，放在结尾 | 用户选择主动提，并接一句对自己工作的信心 |
| 请求交流句 | 用，请求加微信做线上展示 | 用户希望争取到讲工作的机会 |
| 落款 | 姓名和电话，不写邮箱 | 用户的偏好 |

## 三、母版正文（节选）

方括号里是这位用户已经定下来、每封都不变的内容，花括号是留给每位导师的定制槽。

> **邮件主题**：[2027]级博士申请｜[姓名]（[某某大学 硕士]）｜{DNA 分子机器与导师核心方向}方向
>
> 尊敬的{姓}老师：
>
> 您好！
>
> [冒昧致信。我叫某某，目前是某某大学某专业的硕士研究生，师从某教授，预计于 2027 年 6 月毕业。我希望在博士阶段围绕] **{DNA 分子机器与导师核心方向}** [开展研究，因此特向您咨询课题组 **2027 年的博士招生计划**，希望有机会在您的指导下攻读博士学位。]
>
> {经历段：从素材库选两三项。}[这些课题从选题、实验到数据分析和论文撰写，基本由我独立完成。]
>
> [我目前最主要的一项工作是 **某可编程 DNA walker 平台**。（事实底稿：三句，写清在什么结构上、用什么办法编排轨道位点、考察了哪些因素和信号放大的关系。）]{侧重句：选一个角度，接到导师的方向。}
>
> [目前的相关论文与稿件如下：]
>
> [[1] 作者, et al. 题目. ***期刊***. DOI.]
> [**第一作者**；已在线发表；分区信息及来源年份。]
>
> [[2] 同上格式；已在线发表。]
>
> [[3] 同上格式。**第一作者**；In Peer Review（同行评审中）。]
>
> [[4] 同上格式。**第一作者**；Editorial Review（编辑审理中）。]
>
> {导师段：两三句。}
>
> [随信附上**个人简历**、**简要工作介绍**及**博士阶段研究计划**，供您参考。不知您课题组 2027 年是否有合适的博士招生机会？虽然我的院校背景较为普通，但我相信，若有机会向您具体介绍自己的研究工作，其中的一些思路与探索或许能引起您的兴趣。如您方便，也希望能添加您的微信，给我一个线上展示的机会。]
>
> [感谢您在百忙之中阅读这封邮件，期待您的指教。]
>
> [祝您工作顺利，科研进展顺利！]
>
> [姓名]
> [电话（同微信）]

格式约定：自介只加粗研究方向和招生年份；经历段不加粗；核心工作段只加粗平台名称；期刊名加粗斜体；“第一作者”和有利的分区信息加粗；导师段不加粗；附件名加粗。

## 四、母版附表

### 核心工作的侧重点清单

| 角度 | 强调什么 | 适合哪类导师 |
|---|---|---|
| 空间组织 | 轨道位点的序列和间隔可以编排 | DNA 折纸、核酸组装、核酸器件 |
| 局部放大与背景控制 | 位点可及性、局部反应的效率和泄漏 | 核酸诊断、液体活检 |
| 界面反应与催化输出 | 多价界面上的周转如何调节材料的催化活性 | 纳米酶、催化分析 |
| 动力学 | 轨道密度和周转速率的关系 | 单分子、单颗粒成像 |
| 读出耦合 | 动态核酸反应怎样转成电学或光学信号 | 电化学、光电、晶体管传感 |

### 经历素材库

| 来自 | 备选句的内容 | 适合哪类导师 |
|---|---|---|
| 已发表工作一 | 光控的核酸门控结合酶辅助放大，做成电化学适配体传感器 | 响应性探针、电化学传感、适配体 |
| 已发表工作二 | 两条放大路径并行，配合金属有机框架材料的读出 | 核酸放大、功能材料 |
| 编辑处理中的工作 | walker 的表面周转调控纳米材料的类酶活性 | 纳米酶、催化、核酸与材料耦合 |
| 技能 | CHA、HCR、链置换、DNA 四面体、CRISPR 传感 | 核酸诊断、限域反应 |
| 技能（在补课清单里） | caDNAno 折纸结构设计、AFM 表征 | DNA 折纸、核酸组装 |

## 五、同一份母版改给两位导师

导师甲做 DNA 折纸上的级联催化反应器；导师乙做外泌体内 miRNA 的限域核酸检测。两封邮件的身份、成果段、核心工作的事实底稿、结尾完全相同，不同的是下面五处。

| 定制槽 | 给导师甲 | 给导师乙 |
|---|---|---|
| 主题和首段的方向短语 | DNA 分子机器与可编程核酸组装 | DNA 分子机器与核酸分子诊断 |
| 经历段选材 | 轨道位点编排的经验；walker 调控材料催化的工作；caDNAno 与 AFM | CHA 和 DNA 四面体的经验；局部反应组织；荧光动力学 |
| 核心工作段的侧重句 | 空间组织的角度：位点的序列和间隔可以预先编排，希望在几何更明确的平台上继续做 | 局部放大的角度：位点可及性和背景控制，希望做成更小、能在受限空间里工作的核酸机器 |
| 导师段 | 您近期在折纸上组织级联催化的工作；我在轨道编排和催化调控上的经验；希望学习折纸，把轨道和催化位点组织到布局明确的平台上 | 您近期用限域 CHA 检测外泌体 miRNA 的工作；我做过 CHA 和四面体；希望探索面向囊泡分析的小型核酸机器和低背景放大 |
| 没有写的 | 治疗应用；已有折纸方向的研究成果 | 现有的微米级结构可以直接进入囊泡 |

最后一行是这两封各自的红线：对导师甲不把学过的技能写成已有的研究成果，对导师乙不许诺现有体系做不到的事。

遮住导师的名字，从方向短语、选材和导师段可以看出两封信分别写给谁。这就是定制到位的样子。
